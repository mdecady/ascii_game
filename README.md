# Life Roll

Пошаговая игра на двоих про жизнь человека, который рождается по реальной статистике. Графика выполнена в ASCII-арте.

## Идея

Игра случайно "рождает" персонажа: страна, пол и доход семьи выбираются с учётом реальных статистических данных. Дальше игроки по очереди принимают решения в ключевых жизненных ситуациях (учёба, работа, здоровье, отношения). В конце считается итог жизни: побеждает тот, чьи решения привели к лучшему результату.

## Режим игры

Человек против человека, по очереди, на одном компьютере. Оба игрока начинают с одинаковыми стартовыми условиями. На экране всегда видно, чей сейчас ход.

## Правила

- Показатели персонажа: здоровье, счастье, деньги, отношения, достижения.
- Варианты выбора, недоступные по условиям (например, нет денег на университет), заблокированы, при попытке выбрать их игра выдаёт отклик.
- Проигрыш: [например, ранняя смерть или нищета]. Выигрыш: [например, наивысший итоговый рейтинг жизни].

## Технологии

- C# и XAML
- [WPF / Avalonia]
- Паттерн MVVM
- [ReactiveUI / R3]
- Асинхронность: загрузка статистики и расчёт итогов выполняются в фоне, интерфейс не зависает
- Стороннего графического движка нет: ASCII-арт выводится в TextBlock с моноширинным шрифтом

## Структура проекта

- Models: персонаж, события, статистика по странам
- ViewModels: логика экранов и состояние игры
- Views: окна и XAML

## План разработки

1. Каркас: пустой проект, MVVM, ReactiveUI, ASCII в окне
2. Модель персонажа и генерация по статистике
3. Движок событий (данные в JSON, выбор, последствия)
4. Режим на двоих: очередность ходов и экран "чей ход"
5. Условия выигрыша и проигрыша, итоговый экран
6. ASCII-оформление, дополнительные события, доработка
